# Udemy Online Courses Dashboard - Power BI

Dashboard to analyze Udemy courses: Courses, Subscribers, Prices, Lectures, and Reviews.

### Tools Used
- Power BI
- DAX
- Data Cleaning

### Files
- Udemy_Dashboard.pbix - Power BI Dashboard
- udemy.pdf - Full Dashboard Report (PDF)

### Key Insights
- Total Courses: 4K
- Total Subscribers: 12M
- Total Reviews: 574K
- Total Lectures: 147K
- Web Development has the highest subscribers (7.9M)
- Average Price: $66.1
